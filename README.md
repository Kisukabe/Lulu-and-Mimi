# 🇬🇧 Lulu & Mimi — Nền Tảng Học Từ Vựng Tiếng Anh Thông Minh

> Ứng dụng Web hiện đại học từ vựng tiếng Anh toàn diện với **Flashcard 3D**, **Khung từ vựng chi tiết (Dictionary View)**, **Hệ thống phân loại đa tầng** (Topic / Word Form / Idioms / Collocations / Phrasal Verbs), **Tra từ điển chuẩn Cambridge & Free Dictionary**, **Tự tạo Flashcard bằng tay (CRUD)**, **Luyện thi trắc nghiệm phản xạ**, và **Trợ lý AI Google Gemini**.

---

## ✨ 1. Tính Năng Nổi Bật

### 🎴 1.1. Flashcard Lật 3D (3D Flip Cards)
- **Hiệu ứng 3D chân thực**: Lật mặt trước/mặt sau mượt mà bằng CSS 3D Transforms (`rotateY(180deg)`).
- **Phát âm chuẩn IPA**: Cung cấp phiên âm quốc tế chuẩn IPA cả UK (`en-GB`) và US (`en-US`), kèm nút nghe phát âm âm thanh.
- **Phím tắt tiện lợi**:
  - `Space`: Lật thẻ xem nghĩa/câu ví dụ.
  - `←` / `→`: Chuyển đổi qua lại giữa các thẻ.
- **Trạng thái học tập**: Đánh dấu "Đã thuộc" (Mastered) hoặc "Cần ôn lại" (Need Review) để lọc thông minh.
- **Bộ lọc phân loại ngay trên thẻ**: Lọc theo Từ Vựng (Words), Thành Ngữ (Idioms), Cụm Từ (Collocations), Cụm Động Từ (Phrasal Verbs).

### 📖 1.2. Khung Từ Vựng Chi Tiết (Vocabulary Detail View)
- Giao diện tra cứu phong cách Từ điển hiện đại, hiển thị toàn bộ thuộc tính của từ:
  - Dạng từ: Noun, Verb, Adjective, Adverb, Phrase, Idiom.
  - Nghĩa tiếng Việt chuẩn xác.
  - Ví dụ thực tế kèm bản dịch tiếng Việt.
  - Nhóm từ đồng nghĩa (Synonyms) & trái nghĩa (Antonyms).
  - Cụm từ đi kèm thường gặp (Collocations).
  - Gia đình từ (Word Family): Noun, Verb, Adj, Adv liên quan.
- Thanh tìm kiếm tức thời theo từ tiếng Anh, nghĩa tiếng Việt hoặc phiên âm.
- Lọc đa tầng: Loại từ vựng, dạng từ, độ khó, trạng thái học tập.
- Nút sao chép (Copy) nhanh vào clipboard.

### 🔍 1.3. Tra Cứu Từ Điển Cambridge & Free Dictionary
- Tra cứu trực tiếp từ vựng tiếng Anh với dữ liệu từ Free Dictionary API (Wiktionary) và Cambridge.
- Hỗ trợ nghe phát âm trực tiếp với tệp âm thanh MP3 chất lượng cao.
- **1-Click Thêm vào Flashcard**: Tự động đưa từ vừa tra cứu vào kho thẻ cá nhân của bạn.
- Lịch sử tra cứu gần đây được lưu tự động.

### ✏️ 1.4. Tự Tạo Flashcard Bằng Tay (CRUD)
- Biểu mẫu trực quan giúp bạn tự thêm các từ vựng, thành ngữ mới.
- **Tính năng "🔍 Tự điền từ từ điển"**: Chỉ cần nhập từ tiếng Anh, hệ thống tự động điền phiên âm IPA, loại từ, câu ví dụ và từ đồng nghĩa trong 1 giây.
- **Xem trước 3D thời gian thực (Live 3D Preview)**: Thẻ 3D hiển thị và cập nhật trực tiếp theo những gì bạn đang gõ.
- Quản lý danh sách thẻ cá nhân: Chỉnh sửa (Edit), Xóa (Delete).
- **Xuất / Nhập JSON (Export / Import)**: Sao lưu kho thẻ cá nhân hoặc chia sẻ cho bạn bè.

### 📝 1.5. Luyện Thi Trắc Nghiệm Phản Xạ (Quiz)
- Tùy chỉnh số lượng câu hỏi (5, 10, 15, 20 câu) và thời gian đếm ngược (3, 5, 10, 15 phút).
- **Tự động sinh câu hỏi thông minh**: Tự sinh câu hỏi trắc nghiệm 4 đáp án từ kho flashcard mẫu và các flashcard do bạn tự tạo.
- Chấm điểm ngay lập tức với giải thích chi tiết cho từng đáp án.
- Đánh dấu câu hỏi (Bookmark) để ôn lại.
- Bảng kết quả tổng quan kèm hiệu ứng pháo hoa ăn mừng và bộ lọc "Chỉ xem câu sai".

### 🤖 1.6. Trợ Lý AI Google Gemini
- Trò chuyện trực tiếp với AI để giải đáp thắc mắc về ngữ pháp, ngữ cảnh từ vựng.
- Gợi ý câu ví dụ, so sánh sự khác nhau giữa các từ đồng nghĩa.
- **1-Click Thêm vào Flashcard**: AI tự động trích xuất cấu trúc thẻ và bạn có thể lưu thẳng vào bộ nhớ chỉ bằng một nút bấm.

### 📊 1.7. Thống Kê Tiến Độ Học Tập
- Thống kê tỷ lệ thuộc thẻ, số thẻ cần ôn lại.
- Thống kê số bài thi trắc nghiệm đã làm và độ chính xác trung bình.
- Biểu đồ tiến độ phân bổ theo từng loại từ vựng và chuyên đề.
- Lịch sử điểm số các bài thi gần nhất.

### 🌓 1.8. Giao Diện & Trải Nghiệm Người Dùng
- Thiết kế Glassmorphism hiện đại với màu sắc hài hòa.
- Chế độ giao diện: **Sáng (Light)**, **Tối (Dark)**, và **Theo Hệ Thống (System)**.
- Tương thích tốt trên máy tính, máy tính bảng và điện thoại di động.

## 🚀 3. Hướng Dẫn Cài Đặt & Khởi Chạy

### 3.1. Yêu Cầu Môi Trường
- Node.js >= 18.0.0
- npm >= 9.0.0

### 3.2. Cài Đặt Dependencies
```bash
npm install
```

### 3.3. Cấu Hình Biến Môi Trường (Tùy Chọn)
Sao chép file `.env.example` thành `.env`:
```bash
cp .env.example .env
```
*(Nếu muốn sử dụng Trợ lý AI, nhập `GEMINI_API_KEY` từ [Google AI Studio](https://aistudio.google.com/))*.

### 3.4. Khởi Chạy Ứng Dụng (Development)
```bash
npm run dev
```
👉 Mở trình duyệt và truy cập: **http://localhost:5050**

### 3.5. Đóng Gói Sản Phẩm (Production Build)
```bash
# Kiểm tra lỗi TypeScript
npm run lint

# Build production bundle
npm run build

# Khởi chạy server production
npm run start
```
